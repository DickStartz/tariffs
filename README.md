# Tariff Visualization Tool

An interactive web application for understanding the effects of tariffs on imports and tariff revenue.

## Overview

This application visualizes tariff data and allows users to explore the impact of different tariff rates and elasticity values on imports and tariff revenue.

## Features

- Historical visualization of duty rates and import shares
- Interactive inputs for elasticity and tariff rate
- Real-time calculation of imports and tariff revenue based on user inputs
- Responsive design that works on different screen sizes

## How to Use

1. Open the `index.html` file in a web browser
2. View the historical chart of duty rates and import shares
3. Adjust the elasticity and tariff rate inputs to see how they affect imports and tariff revenue
4. Hover over the charts to see exact values

## Data

The application uses data from the `utoandGDP.xlsx` file, which contains historical information about:
- Year
- Duty rate
- Import share
- Duties
- Imports

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js for data visualization
- SheetJS for Excel file parsing
